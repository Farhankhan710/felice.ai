# felice starter — frontend prototype

## Open in Acode (Android)
1. Extract this ZIP on your phone.
2. In Acode, open the extracted `felice-ai` folder.
3. Open `index.html` and use Acode Preview or your browser.

## Files
- `index.html` — page structure, navigation, account modal and cookie banner
- `style.css` — responsive off-white/black theme, animations and layout
- `script.js` — navigation, local demo outputs, demo credits and interactions
- `assets/logo.png` — felice wordmark used in the navbar and favicon

The old `assets/logo.svg` has been removed.

## Included in this frontend prototype
- Responsive navigation and mobile menu
- Caption, prompt-to-video, text-to-image, image-to-video, AI voice, script and subtitle screens
- Smooth entrance animations for the header, hero, cards, tool screens, cookie banner and account modal
- Proper outlined profile/account icon
- Local demo outputs and demo credits stored in the browser
- Cookie preference banner
- Login/signup interface with required Terms & Privacy checkbox
- English and Hinglish prompt entry (Hindi script input is also accepted)

## Important before public launch
This is still a frontend prototype. It does not provide real AI image/video/audio generation, secure authentication, payments, cloud project storage, or a production admin system. Demo credits are stored locally and are not secure. Do not collect real passwords or personal data until a secure backend, database and authentication system are implemented. The cookie banner stores a local preference only and is not a complete legal compliance solution.
